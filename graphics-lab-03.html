This is a standalone graphics experiment, not an upgrade to your live v0.8.1 game. This lab continues the graphics work by improving character facing, softening the animation transitions, and making movement feel more natural while keeping the repaired roof and lighting from Lab 02.

Heads-up: the human model loads from a public GLB reference library. If the model download fails, a procedural fallback will appear. An internet connection is required, just like your current game.

No purchases, installs or changes to your main game save. Desktop and mobile share the same website. The detailed model is still a temporary animation reference, but this build focuses on making it face the correct direction and move less stiffly.
