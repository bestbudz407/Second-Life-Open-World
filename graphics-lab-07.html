Aiming closer to your realistic life-sim target.

This is a standalone graphics experiment, not an upgrade to your live v0.8.1 game. This version uses your reference image as a visual north star: warm suburban sunrise lighting, a richer life-sim HUD, cleaner neighborhood presentation, and a more premium mobile/desktop look while keeping the movement foundation from the prior build.

Heads-up: the human model loads from a public GLB reference library. If the model download fails, a procedural fallback will appear. An internet connection is required, just like your current game.

No purchases, installs or changes to your main game save. Desktop and mobile share the same website. This build is mainly about world presentation and interface direction. Character systems are preserved, but the biggest changes are visual.
